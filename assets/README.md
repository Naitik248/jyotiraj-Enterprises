# Product image assets

Each product card points directly to one file in this folder:

- `orbit-one-ultra.svg`
- `atom-pro.svg`
- `flux-fold.svg`

To replace a visual, overwrite the matching file (SVG, PNG, WebP, or JPG) and update its `src` in `index.html` if the file extension changes. The card crops and scales images automatically using the `.product-art img` rule in `styles.css`.
